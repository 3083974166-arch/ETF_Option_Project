# 面试问答：回答后要能指到代码与证据

1. **你的核心贡献是什么？** 数值定价与验证、带来源的数据清洗、平价carry估计、可核对的时序和账本。当前完整市场实证未完成，不能声称发现可交易Alpha。
2. **BSM假设明显不成立，为什么还用？** 它提供统一的价格—IV转换坐标和局部风险度量，不意味着恒定波动率是真实市场规律。
3. **为何不能直接q=0？** ETF分红及有效carry会改变平价；遗漏它会污染IV。用同日同到期同K同单位C/P推F，再推q。
4. **q为什么可能不稳定甚至为负？** 报价异步、买卖价差、近到期放大、融资/借券约束都可能影响它。先查数据，不机械截成0。
5. **Brent和Newton怎么取舍？** Brent括区内稳健，Newton靠Vega可能更快但低Vega危险。本项目Newton越界就二分；有边界和迭代失败处理。
6. **如何证明Greeks写对？** 对价格函数做中心有限差分，Delta/Gamma/Vega/Theta/Rho分别比对；Theta注意对剩余T的负号和年单位。
7. **何时IV反不出来？** 超无套利边界、到期、零时间价值、低Vega噪声或根超合理搜索范围。记录原因，不填常数掩盖问题。
8. **为何单合约数据不够？** 曲面需要同日横截面的执行价和期限；回测需要持仓连续价格和当时可选合约全集。当前链回填历史会有幸存者偏差。
9. **标准10000份为什么不能写死？** ETF分红引发合约调整；单位、执行价和代码可能变化。当前版本按条款映射并剔除调整合约。
10. **价格用复权还是不复权？** 可成交ETF价格及BSM输入用不复权S，RV用含分红总回报；ETF现金账本另计分红及空头补偿。
11. **ATM与曲面怎么构造？** OTM报价按log(K/F)拼接，ATM在0处插值；30日先插总方差再还原IV；2D/3D不外推。不是SVI无套利拟合。
12. **IV减RV等于风险溢价么？** IV减past RV只是信号；IV减future RV是事后实现差值。严格风险溢价涉及测度下的预期，常用方差尺度。
13. **你怎么避免未来函数？** past窗口截至t，信号及选合约在t，执行在t+1；未来RV仅作标签。通过修改未来行情/标签验证过去信号和账本不变。
14. **为什么要purge？** 临近切分的训练特征，其未来20日标签可能跨入OOS。必须按label_end剔除，而非仅看date。
15. **为什么HAC？** 未来RV标签重叠会造成序列相关，普通标准误可能过小。HAC不解决所有模型错误，也不保证小样本显著性可靠。
16. **交易信号是什么？** IV相对past RV偏低时买一组近月ATM跨式；阈值预先固定。这是基线假设，需要真实样本检验，不能把past RV当无误预测。
17. **为何不卖跨式？** 基础版用多头简化裸卖保证金与极端风险；不声称已经实现空头期权风控。多头仍会持续损耗权利金。
18. **Delta中性如何实现？** 目标ETF份数是负的合约单位加权Delta，按100份取整，用上一日Delta下一收盘执行。日频、限仓和券源使中性有残差。
19. **做空ETF有什么问题？** 历史券源、借券费用、召回和分红补偿。默认禁止，显式假设可借时计借券费用，仍不能当作已证实可执行。
20. **你的成本是否只含手续费？** 还有两边价差、额外滑点、ETF按成交额成本、借券和负现金融资。成本翻倍连报价半价差也一起翻倍。
21. **遇到到期怎么办？** 到期前14自然日退出，不模拟行权交割。50ETF为实物交割，不按现金结算指数期权处理。
22. **缺失持仓报价怎么办？** 当前严格报错停止，保留失败清单。未来可加入有明确规则的估值区间，但不能简单前填来压低回撤。
23. **P&L怎么归因？** 期权持仓价值变动、ETF价格及分红变动、交易/融资/借券成本；逐日与现金加资产权益变化核对。
24. **Sharpe与胜率的定义？** 日收益均值/标准差×√252，现金基准0；胜率为非零损益日胜率。不是每笔交易胜率，不能偷换口径。
25. **OOS看完再选最好阈值算过拟合吗？** 算二次使用OOS，需要另留最终未见数据。敏感性表应完整报告，不能只挑最高收益。
26. **你会如何继续扩展？** 先补经核验的历史链、同步盘口、券源和交易日历，再做期限严格匹配、静态套利诊断、carry/利率敏感性与更多时期。不是先堆更大的模型。
27. **你现在能证明策略赚钱吗？** 不能。现在能证明被测试的定价、数据时序和账本功能可运行，且公开接口能取到部分真实样本；缺完整历史链不能作收益主张。
28. **怎么证明你真的懂，而不只是拿到AI代码？** 现场手算一笔账本，解释一个测试失败，修改一个假设并预判影响，展示自己做的扩展及复现实验记录。
