# 数据规范与市场微观约束

## 统一约定

CSV UTF-8；日期为 `YYYY-MM-DD`；日频均代表北京时间同一交易日收盘。价格按一份ETF计价，合约单位另列。金额为人民币；波动率及连续复利利率用小数，20%写0.20。BSM期限 ACT/365，RV年化252。

同日并不自动意味着同步：收盘最后成交价可能早于15:00、买卖报价可能过时。研究者必须确认原始时间戳；目前日频CSV不会替你证明报价同步。价差、平价分散程度只能揭示部分问题。

原始数据永不改写为模型估计。下载API失败不填0；无成交不是价格为0；OI缺失不冒充已知持仓量。源站有权限/频率要求时遵循要求，不绕过限制。

## 必需文件

### options.csv

| 字段 | 内容 |
|---|---|
| date, contract_id | 交易日、以字符串保存的交易所合约代码；组合唯一 |
| close | 每份ETF的期权收盘价，不是每张总价 |
| bid, ask | 同步买卖一价；没有则留空，不能都填close |
| volume | 当日成交张数；缺失会剔除 |
| open_interest | 持仓张数；可缺，但启用min_oi后缺失必须剔除 |
| source | 来源、口径、原始文件/时间戳引用 |
| is_synthetic | 真实来源写False；正式入口拒绝True或缺失 |

bid/ask俱全时用中价估值；否则用close，成交成本必须选择proxy情景。有bid无ask等不完整盘口应剔除。中价不等于可成交价。现有Sina历史接口返回OHLC与量，没有历史买卖盘口和OI。

### contracts.csv

| 字段 | 内容 |
|---|---|
| contract_id, cp | 合约代码、C或P |
| K, expiry | 生效执行价、真实到期日期 |
| multiplier | 每张对应ETF份数 |
| adjusted | 布尔值，调整合约True；当前研究剔除它们 |
| valid_from, valid_to | 条款生效范围，首尾包含；同代码范围不能重叠 |
| source | 官方文件链接/版本/快照的可追溯说明 |

到期日通常为第四个星期三但有节假日规则，**不使用简单日历公式替代交易所日期**。标准合约10000份，分红调整可能不同。必须获取实际历史条款，而不是用当前执行价回填过去。

`official_contracts.csv` 是用户从交易所文件归一化后的对照接口：`asof,contract_id,cp,K,expiry,multiplier`。工具按asof检查映射、类型、执行价、到期日和单位，输出逐条差异；这个检查不保证历史合约全集完整，也不自动验证文件来源真实性。保留原始PDF/CSV与下载地址，文件名带日期。

### underlying.csv

`date,S,total_return_close,cash_dividend,source,is_synthetic`

S是不复权可交易收盘价，不能把后复权价放进BSM。cash_dividend是该交易日除息的每份现金分红，支付/应收在本模型于除息日计入，未细分支付延迟及税费。total_return_close是含分红总回报指数，用于RV。下载脚本根据用户核实的分红事件构造：

`TR_t = TR_(t-1) × (S_t + D_t) / S_(t-1)`。

`dividends.csv`：`date,cash_dividend,source`；无事件需保留表头。必须保证样本完整。借出ETF空头需支付分红补偿，账本会通过负的hedge数量处理。

### rates.csv

`date,r,available_date,source`。r为每日估值使用的年化连续复利利率，available_date不能晚于date；使用当天已经发布的利率，或将上一已知值明确扩展到估值日。脚本不自动后向填充。

当前使用单条每日利率而非完整期限曲线，需要在报告中写出选用哪类利率和期限近似，做利率敏感性扩展。利率影响平价隐含q，不能把r缺失变成q=0。

## 清洗顺序

唯一性与日期映射 → 标的/利率合并 → 缺失与非法值 → 流动性/近到期/盘口 → 同日同到期同执行价同单位C/P配对 → 推导远期 → 无套利边界 → IV反解 → 极端IV。

默认过滤：至少7自然日、成交10张、价格0.0001、相对价差≤50%、|log(K/S)|≤0.25；OI默认不启用。调整合约剔除。近到期平仓提前到14日，避免模型Theta/Gamma失稳及真实交割。

平价公式 `F = K + exp(rT)(C-P)`，`q = r - log(F/S)/T`。每组至少2个执行价；对F取中位数，极差相对中位数超过1.5%则该组拒绝。q是有效连续carry，不能直接解释为精确预测的分红率。离散分红、利率期限结构、短售约束及报价异步都会造成差异。缺配对时不回退q=0。

## 数据足够做什么

- 单合约历史：接口验证及单合约数据检查，不能生成横截面波动率曲面。
- 当前完整链：可研究当日形状，不能推出跨周期收益。
- 连续历史完整链+标的+分红+利率：可做历史价格研究。
- 再有同步盘口、交易日历、券源/资金约束：才更接近可交易回测。

本次保留的真实probe数据属于前两类接口验证材料；不连接不同时期的期权和ETF价格。2022年的单合约与2025年的ETF绝不能硬拼。
