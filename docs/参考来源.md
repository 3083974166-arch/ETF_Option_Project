# 参考来源与核查日期

联网核查日期：2026-09-30。接口定义与交易规则可能更新；重新研究应再次核查，尤其不能拿2015年的初始持仓限额当今天的限制。

1. [AKShare官方期权接口文档](https://akshare.akfamily.xyz/data/option/option.html)：Sina日线、月份、代码、实时报价等接口；本项目优先用安装包调用，保留原始返回。
2. [AKShare官方代码库](https://github.com/akfamily/akshare)：排查字段变化与接口失效。项目定价及回测代码为独立实现，不依赖平台Greeks。
3. [上交所50ETF期权合约规格](https://english.sse.com.cn/markets/derivatives/overview/50etf/)：欧式、实物交割、标准单位10000份等。
4. [上交所合约规格入口](https://www.sse.com.cn/assortment/options/contract/)：正式条款检索入口。
5. [上交所2025年12月合约调整公告](https://www.sse.com.cn/assortment/options/disclo/update/c/c_20251216_10801845.shtml)：分红后执行价、合约单位会改变，是不能固定写死单位的实际依据。
6. [SciPy brentq文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.brentq.html)：带括区的求根方法；本项目自主构建定价目标、边界和括区，调用通用求根器。
7. [statsmodels稳健协方差文档](https://www.statsmodels.org/stable/generated/statsmodels.regression.linear_model.RegressionResults.get_robustcov_results.html)：用于重叠未来RV标签的HAC标准误。

BSM和风险中性定价来自经典期权定价框架；本项目的隐含carry来自看涨看跌平价，不代表BSM经济假设在市场中严格成立。线性曲面插值只负责展示，没有实施无静态套利的SVI/SSVI校准。
