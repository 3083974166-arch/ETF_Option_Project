# Overleaf 使用说明

1. 在 Overleaf 首页选择 **New Project → Upload Project**。
2. 上传项目根目录旁的 `宝宝教程_Overleaf.zip`，或只上传本目录中的 `main.tex`。
3. 打开 **Menu → Compiler**，选择 **XeLaTeX**。
4. 点击 **Recompile**。首次编译可能需要稍等片刻。

`main.tex` 已包含中文排版、目录、数学公式和“代码入口／动手练习／面试会问”提示框，不依赖本地图片或字体文件。

如果中文没有正常显示，请先确认编译器是 XeLaTeX，而不是 pdfLaTeX。
