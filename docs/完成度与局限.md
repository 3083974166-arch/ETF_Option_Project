# 完成度与局限

## 已实现的工程能力

定价与数值反解；有限差分验证；按生效日期的条款映射；流动性、无套利及异常诊断；C/P平价远期/carry；批量IV和Greeks；ATM/Smile/Skew/期限/2D与3D图；历史和未来RV的隔离；时间切分及标签purge；HAC线性预测；跨式与ETF对冲；成本、约束、提前到期退出；P&L账本核对；IS/OOS；9类参数/成本/频率/过滤情景；来源和运行清单；命令行；pytest；教学notebooks；中文文档。

## 尚未完成的真实市场实证

当前公开接口实际返回部分真实数据，但未取得足够的、经过交易所核验的历史完整期权链。提供下载器与规范，不根据代码猜执行价和到期日，不把当前列表伪装成历史合约全集。

未验证历史盘口可成交性、券源和完整分红/利率输入。因此没有可展示的真实净值或Sharpe。`data/raw/probe/` 是接口成功证据，不是策略证据。

正式pipeline只接受标注真实来源的输入，但标注是数据提供方声明，不是自动真实性认证。manifest使用 `REAL_SOURCE_UNVERIFIED` 以避免把输入标签误写成官方核验。

## 当前模型明确简化

- 日频收盘模拟；信号/合约选择/Delta滞后一日；不能表示盘中冲击、排队成交、限价与涨跌停。
- 买入跨式，无裸卖期权保证金模型；ETF可借券仅为显式假设，默认禁空；没有券源召回和限额的历史时序数据。
- 到期前退出，不实现实物行权交收。未获退出报价会失败，不假定现金结算。
- 调整合约整体剔除，未实现持有跨分红调整的合约变更账本；如果所持标准合约后来被调整，数据中断会触发错误，须缩短区间或扩展公司行动处理。
- 每日一条利率近似整条期限结构；q是有效carry，不是严格离散分红模型。
- 图是描述性插值，无完整静态套利约束；未做SVI/SSVI。
- 20交易日RV与30自然日IV近似对齐；日频RV不能捕捉完整盘中路径。
- 现金正余额利息设为0；负现金融资和空头借券计费；股息在除息日记应收/应付，未处理结算时滞和税费。
- ETF目标按100份取整；调整频率按观测交易日计，输入underlying必须含完整真实交易日，不会自动替你核验交易所日历。
- Sharpe为原始日收益、基准0；win rate为非零损益日胜率。成交模型基于实际时点价格作可用性/资金拒单检查，无法还原逐笔成交。
- OOS稳健性用于诊断，查看之后再调参需要新的保留集。

## 可直接用于实习展示的部分

展示定价验证、错误处理、真实接口校验记录、代码结构、数据规范、无未来函数测试和损益核算方法。面试时能解释一个自己复核过的实验，比填虚假收益数字更有说服力。

## 后续实证完成的验收门槛

具备完整且可追溯的历史合约、同步估值输入、分红、利率、充分的样本内与未见样本外时期；报告缺失/剔除分布；明确盘口或代理成本；分别报告受券源约束和假设可借场景；保存输出manifest并核查异常日。届时再填写研究报告的真实指标。
